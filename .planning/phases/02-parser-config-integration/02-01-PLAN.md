**config.py:** Add two fields to RAGAnythingConfig, placed after the Audio Processing section (before Multimodal Processing section). Follow the exact field pattern used by audio fields:

```python
# Spreadsheet Processing Configuration
# ---
enable_direct_spreadsheet_parsing: bool = field(
    default=get_env_value("RAG_ANYTHING_DIRECT_SPREADSHEET", True, bool)
)
"""Enable direct spreadsheet parsing without LibreOffice conversion."""

spreadsheet_max_rows_per_chunk: int = field(
    default=get_env_value("RAG_ANYTHING_SPREADSHEET_MAX_ROWS", 150, int)
)
"""Maximum rows per content_list chunk when parsing spreadsheets directly."""
```

Note: Per user decision, env var prefix is `RAG_ANYTHING_` (differs from existing fields that have no prefix — this is intentional).

**parser.py:** Add `parse_spreadsheet()` method to `MineruParser` class, placed immediately after `parse_audio()` (before `parse_document()`). Follow parse_audio() pattern exactly:

1. Guarded import of `SpreadsheetParser` and `SpreadsheetConfig` from `raganything.spreadsheet`
2. Convert file_path to Path, check exists
3. Construct `SpreadsheetConfig(max_rows_per_chunk=max_rows_per_chunk)` inline
4. Try `SpreadsheetParser(config).parse(file_path)`
5. On success: log info with block count, return content_list
6. On ImportError: re-raise (hard error per user decision — `except ImportError: raise` BEFORE the general except)
7. On any other Exception: log WARNING with filename and exception type name, fall back to `self.parse_office_doc(file_path, output_dir, lang, **kwargs)`

Method signature:
```python
def parse_spreadsheet(
    self,
    file_path: Union[str, Path],
    output_dir: Optional[str] = None,
    lang: Optional[str] = None,
    max_rows_per_chunk: int = 150,
    **kwargs,
) -> List[Dict[str, Any]]:
```

CRITICAL: Do NOT store anything on `self` — MineruParser has `__slots__ = ()`. All config flows as method parameters.

Also add `SPREADSHEET_FORMATS = {".xls", ".xlsx"}` to the `Parser` base class constants (alongside OFFICE_FORMATS, IMAGE_FORMATS, etc.) and remove `.xls` and `.xlsx` from `OFFICE_FORMATS`. Then update `MineruParser.parse_document()` to route SPREADSHEET_FORMATS through `parse_spreadsheet()` instead of `parse_office_doc()`.
