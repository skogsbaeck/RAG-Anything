**`format_cell_value(value: Any) -> str` function:**
Coerce openpyxl cell values to clean strings per locked decisions:
- `None` -> `""`
- `bool` -> `"TRUE"` / `"FALSE"` (must check bool BEFORE int, since `isinstance(True, int)` is True in Python)
- `int` -> `str(value)`
- `float` -> `str(value)`
- `datetime.date` / `datetime.datetime` -> `value.isoformat()` (check datetime before date since datetime is subclass of date)
- `str` -> pass through to `sanitize_cell()`
- Any other type -> `str(value)` as fallback

**`sanitize_cell(value: str) -> str` function:**
Sanitize markdown special characters in string cell values:
1. Replace `\r\n`, `\n`, `\r` with single space (order: `\r\n` first to avoid double replacement)
2. Replace `|` with `\|`
3. Strip leading/trailing whitespace
Return sanitized string.

**`build_merge_map(worksheet) -> dict[tuple[int, int], dict]` function:**
Build a lookup dict from (row, col) -> merge info. Iterate `ws.merged_cells.ranges`. For each range:
- Compute `span_rows` and `span_cols`
- Skip degenerate 1x1 merges
- For every cell in the range, store `{"is_anchor": bool, "span_rows": int, "span_cols": int}`
Parameter `worksheet` is typed as `Any` to avoid importing openpyxl at module level.

**`strip_empty_edges(rows: list[list[Any]]) -> list[list[Any]]` function:**
Remove trailing empty columns and trailing empty rows from a 2D list of cell values.
- A column is empty if all values in that column are `None` or `""`
- A row is empty if all values in that row are `None` or `""`
- Strip from the RIGHT (trailing columns) and BOTTOM (trailing rows) only
- Do NOT strip leading rows/columns (locked decision: always start at A1)
- Return the trimmed 2D list. If everything is empty, return `[]`
