**Class: `SpreadsheetParser`**

```python
class SpreadsheetParser:
    def __init__(self, config: SpreadsheetConfig | None = None) -> None:
        self.config = config or SpreadsheetConfig()
```

**Public method: `parse(self, file_path: str | Path) -> list[dict]`**
Main entry point. Returns a list of content_list items (dicts).

Implementation:
1. Guard clause: validate file exists, raise `FileNotFoundError` if not
2. Determine extension: `.xlsx` -> `_parse_xlsx()`, `.xls` -> `_parse_xls()`, else raise `ValueError`
3. Return the result

**Private method: `_parse_xlsx(self, file_path: Path) -> list[dict]`**
1. Guarded import: `import openpyxl` inside the method (ImportError with helpful message)
2. Load workbook: `openpyxl.load_workbook(str(file_path), data_only=True, read_only=False)` — `data_only=True` for formula values, `read_only=False` for merged cell access
3. Get workbook filename for captions: `file_path.name`
4. Iterate sheets in tab order: `for sheet_idx, ws in enumerate(wb.worksheets):`
5. Skip hidden sheets: check `ws.sheet_state != "visible"` -> skip, log debug
6. Read all rows into a 2D list: `rows = [[cell.value for cell in row] for row in ws.iter_rows()]`
7. Check empty: if all values are None -> skip, log debug
8. Call `strip_empty_edges(rows)` — if result is empty, skip
9. Build merge map: `merge_map = build_merge_map(ws)`
10. Render to markdown: `_render_sheet_to_markdown(rows, merge_map)`
11. Chunk if needed: `_chunk_rows(rows, merge_map, sheet_name, sheet_idx, workbook_name)`
12. For each chunk, build content_list item dict

**Private method: `_parse_xls(self, file_path: Path) -> list[dict]`**
1. Guarded import: `import xlrd`
2. `book = xlrd.open_workbook(str(file_path))`
3. Iterate sheets: `for sheet_idx in range(book.nsheets):`
4. Skip hidden: `book.sheet_visibility(sheet_idx) != 0` -> skip
5. Read rows into 2D list from xlrd API: `sheet.cell(r, c).value`
6. Handle xlrd date cells: `xlrd.xldate_as_tuple()` for cells with `ctype == xlrd.XL_CELL_DATE`
7. Build merge map from `sheet.merged_cells` (returns list of `(rlo, rhi, clo, chi)` — 0-based, exclusive end — convert to 1-based inclusive for compatibility with the merge map format)
8. Same rendering and chunking pipeline as xlsx

**Private method: `_render_sheet_to_markdown(self, rows: list[list[Any]], merge_map: dict) -> str`**
Render a 2D list of cell values into a GFM markdown table string.

1. First pass: format all cell values using `format_cell_value()`, applying merge annotations
   - For each cell at (row_1based, col_1based), check merge_map
   - If anchor with span > 1x1: append ` [merged {span_rows}x{span_cols}]` to formatted value
   - If sibling (not anchor): force to `""`
   - If not in merge_map: use formatted value as-is
2. Build header row: first row of data, pipe-separated: `| val1 | val2 | ... |`
3. Build separator row: `| --- | --- | ... |` (one per column)
4. Build data rows: remaining rows, pipe-separated
5. Join all rows with `\n`

**Private method: `_chunk_rows(self, rows, merge_map, sheet_name, sheet_idx, workbook_name) -> list[dict]`**
Split rows into chunks and produce content_list items.

1. If `len(rows) <= self.config.max_rows_per_chunk`: produce single item
2. Otherwise, split rows at `max_rows_per_chunk` boundaries (no overlap, per research recommendation)
3. For each chunk:
   - Render chunk rows to markdown via `_render_sheet_to_markdown()`
   - Build caption: For single chunk: `["{workbook_name} - Sheet: {sheet_name}"]`. For multi-chunk: `["{workbook_name} - Sheet: {sheet_name} (rows {start}-{end} of {total})"]`
   - Build item: `{"type": "table", "table_body": markdown_str, "table_caption": [caption], "page_idx": sheet_idx}`
4. Return list of items

IMPORTANT: When chunking, the merge_map row references are 1-based (from openpyxl). Adjust chunk row indices accordingly so merge annotations appear correctly in chunked output. For the chunk starting at row index `i` in the 0-based `rows` list, the 1-based row number is `i + 1`.
