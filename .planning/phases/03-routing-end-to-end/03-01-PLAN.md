Add a module-level helper function:

```python
def _none_ratio_exceeds_threshold(content_list: list[dict], threshold: float = _FORMULA_NONE_THRESHOLD) -> bool:
    """Return True if the ratio of None/empty cells exceeds the threshold.

    Counts cells across all table_body markdown strings in content_list.
    A cell is 'empty' if its stripped content is empty or a single dash.
    """
```

Implementation: iterate over items in content_list where type=="table" and table_body is a string. For each table_body, split on newlines, skip the header separator line (contains only dashes and pipes), split each row by "|", strip each cell. Count total cells and empty cells (empty string or "-"). Return `total > 0 and (empty / total) > threshold`.

Then modify `parse_spreadsheet()`: after the line `content_list = SpreadsheetParser(config).parse(file_path)` and the logger.info line, add the threshold check:

```python
if _none_ratio_exceeds_threshold(content_list):
    self.logger.warning(
        f"Spreadsheet {file_path.name} has >10%% None cells "
        f"(likely uncached formulas), falling back to LibreOffice"
    )
    return self.parse_office_doc(file_path, output_dir, lang, **kwargs)
```

IMPORTANT: This threshold check must go INSIDE the try block, AFTER SpreadsheetParser.parse() succeeds but BEFORE returning. It must be BEFORE the `return content_list` line. The existing except blocks (ImportError and generic Exception) remain unchanged.

Do NOT put the threshold check inside spreadsheet.py -- it is a fallback decision that belongs in the parser orchestration layer.
